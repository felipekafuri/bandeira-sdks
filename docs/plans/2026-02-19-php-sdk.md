# PHP SDK + Laravel Integration Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a production-ready PHP SDK for Bandeira with behavior parity to existing SDKs and first-class Laravel integration in one package.

**Architecture:** The package will include a framework-agnostic core client (`Client`, `Config`, `Context`) that refreshes on-demand using PSR-18 HTTP dependencies, plus optional Laravel classes (service provider, facade, context resolver). Strategy/constraint evaluation will mirror existing SDK semantics and shared fixtures in `testdata/flags.json`.

**Tech Stack:** PHP 8.1+, Composer, PSR-7/17/18, PHPUnit, Orchestra Testbench, GitHub Actions

### Task 3: Implement Core Client and Evaluator

**Step 1: Implement transport + cache refresh**

- Implement `refresh()` to fetch `/api/v1/flags` and atomically replace cache.
- Implement stale check in `isEnabled()` using `pollInterval` TTL.
- On stale refresh error: retain last-known cache and continue evaluation.

**Step 2: Implement strategy evaluation parity**

- OR between strategies.
- `default`, `userWithId`, `gradualRollout`, `remoteAddress`.
- Unknown strategy returns true after constraints pass.

**Step 3: Implement constraint evaluation parity**

- `IN`, `NOT_IN`, `STR_CONTAINS`, `STR_STARTS_WITH`, `STR_ENDS_WITH`.
- `NUM_EQ`, `NUM_GT`, `NUM_GTE`, `NUM_LT`, `NUM_LTE`.
- `DATE_AFTER`, `DATE_BEFORE` with RFC3339 parsing.
- `inverted` and `case_insensitive` handling.

**Step 4: Implement helpers**

- `splitMulti` supports commas and newlines.
- FNV-1a 32-bit hash mod 100 for rollout bucketing.
